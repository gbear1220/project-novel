# 자동검사 작동 범위와 한계

- `세계관_정본.json`은 프로젝트 상태를 파싱 가능하게 제공한다.
- Python 스크립트는 **문맥을 이해하는 문학 비평가가 아니다**. 날짜와 주요 단어의 존재, 원본 변경 여부, 제안/확정 혼동 가능성을 빠르게 알려준다.
- '원본 3화에서 2007'은 보존 문서이므로 정상이다. 보정 초고에는 2007년 표현이 남아 있으면 확인이 필요하다.
- 일부 시점의 2007/2008 회상은 합법적으로 등장할 수 있으므로 자동 경고를 근거로 무조건 치환하면 안 된다.
- 시간축 체크는 2009년 11월 14~25일의 **제안된** 사건 배치가 서로 충돌하는지만 살핀다.

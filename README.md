# 미래안 범죄 스릴러 — Codex 집필 작업실

> 이 문서는 **소설 집필을 위한 프로젝트 입구**입니다. 원본을 보존한 상태에서 세계관과 회차를 일관되게 관리합니다.

## 빠른 시작
1. 저장소를 `git clone https://github.com/gbear1220/project-novel.git`으로 복제한다.
2. 프로젝트 폴더에서 터미널을 연다. UTF-8 환경 권장.
3. 설치된 Codex CLI와 계정 모델 이용 권한을 확인한다.
4. `codex -m gpt-6.1-sol` 을 실행한다. 추천 추론 수준: High.
5. `04_집필/01_작업시작_프롬프트.md` 전문을 첫 메시지로 붙여 넣는다.
6. 다음 화 집필은 `04_집필/02_4화_집필_프롬프트.md`를 이용한다.

## 파일 지도
| 경로 | 용도 | 상태 |
|---|---|---|
| `AGENTS.md` | Codex의 작업·승인·검증 규칙 | 고정 운영 규칙 |
| `00_원본/` | 사용자 업로드 원본 1~3화 | **절대 덮어쓰지 않음** |
| `01_설정/정본_세계관.md` | 사용자 확정 사항과 후보 설정 구분 | 정본/후보/미결 분리 |
| `01_설정/세계관_정본.json` | 파이썬 등으로 검색 가능한 구조화 설정 | 자동 파싱 가능 |
| `01_설정/인물설정.md` | 인물 동기, 관계, 서술 제약 | 근거 표시 |
| `01_설정/미래안_규칙.md` | 예지와 추론의 정의, 모순 방지 규칙 | 미결 표시 |
| `01_설정/사건연대표_2009.md` | 과거와 2009년 현재의 사건 시계 | 현재 날짜는 편집 제안 |
| `01_설정/장편_서사설계.md` | 사건 난도·대칭점·자수 결말의 구조 | 방향 고정, 세부 후보 |
| `02_편집/` | 실제 수정 내역, 오류 장부, 문체 규약 | 편집 작업 |
| `03_수정원고/` | 연대·제도·내부 모순을 우선 보정한 1~3화 | **편집 초안; 승인 전** |
| `04_집필/` | Codex 실행 프롬프트와 4화 기획 | 실행 지시 |
| `scripts/` | 연대·파일·정본 검사, 문맥 요약 생성 | 표준 라이브러리 사용 |
| `reports/` | 검사 결과 출력 장소 | 내용 생성 가능 |

## 핵심 원칙
- 저자 확정 사실과 편집자의 추론을 반드시 분리한다. `CONFIRMED` / `PROPOSED` / `OPEN`.
- 2009년 배경은 확정, 2009.11.14~25의 날짜별 안배는 **편집 제안**이다.
- 단순히 무슨 일이 가능한지보다, 무엇이 *이미 원고에서 증명되었는가*를 우선한다.
- 원본 1~3화의 기조(범죄·응징·잔혹성·영화적 연출)를 일방적으로 제거하지 않는다.
- 저자의 최종 의도는 '사적 제재를 행해 온 진호가 결국 스스로 법에 선다'는 인간성 회복 서사다.
- 신임 천재 수사관은 4화부터 투입한다. 신원·이름은 아직 미정이다.

## 유용한 명령
```powershell
python scripts/check_continuity.py
python scripts/build_context.py --output reports/집필_컨텍스트.md
codex -m gpt-6.1-sol
```

*프로젝트 내 모든 파일은 UTF-8로 저장되어 있다. 코덱스가 설정을 일괄 수정하거나 원본을 덮어쓰기 전에 차이점 보고와 사용자 승인을 요구하도록 설계했다.*
